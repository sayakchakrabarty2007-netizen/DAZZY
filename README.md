# DAZZY
DAZZY is an ultra-compact, 1-DOF-per-leg quadruped robot engineered around a minimalist 70x25mm spine. Powered by an ESP32-S3 and four high-torque 8.4V servos, it uses a 4-bar crank-rocker linkage and spring-return system for lightning-fast gaits. Built with PLA/PETG and driven by a 2S 70C LiPo for a maximum power-to-weight ratio.
